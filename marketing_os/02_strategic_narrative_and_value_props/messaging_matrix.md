## 4. Messaging Consistency & QA Validation Protocol

Before publishing any marketing asset, the operator must execute this 3-point QA check against the Messaging Matrix:
1. **Persona Alignment**: Does the copy strictly match the Tone, Hook, and Value Proposition designated for that audience segment?
2. **Surface Verification**: Does the CTA link route exclusively to the approved URL endpoint (`zucity.org/en/all`, `zucity.org/en/calendar`, JGN Discord, `/network`)?
3. **Negative Boundary Scan**: Does the copy completely avoid all prohibited red-line claims (no premature megacity claims, no crypto jargon on public consumer surfaces, no extractive arbitrage framing)?
