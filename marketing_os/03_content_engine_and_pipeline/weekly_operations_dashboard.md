## 2. The 5-Phase Weekly Marketing Operating Rhythm

To eliminate ad-hoc chaos, guarantee editorial quality, and maintain a sustainable pace for creators and on-site operators, the marketing organization adheres strictly to an **8-day production cycle across 5 distinct operational phases**:

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                 THE 5-PHASE WEEKLY OPERATING RHYTHM                                  │
├──────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                      │
│   PHASE 1: MONDAY PLANNING & DATA REVIEW (09:00–10:30 JST)                                           │
│   • Reconcile trailing 7-day conversion telemetry (GA4, Stripe, Luma).                               │
│   • Assign the 10 content pillars across X, IG, Substack, and Discord (40/30/20/10 mix).             │
│   • Triage active P0–P3 blockers and issue raw media requests to Komoro on-site team.                │
│                                      ▼                                                               │
│   PHASE 2: TUESDAY–THURSDAY PRODUCTION & INGESTION (Async & Staged)                                  │
│   • Ingest RAW photos/videos into /raw_media/ vault; transcribe audio field logs.                    │
│   • Execute 6-stage transformation: Raw -> Observation -> Angle -> Platform Format.                  │
│   • Draft high-converting X threads, IG carousels/reels, and Substack long-form essays.              │
│                                      ▼                                                               │
│   PHASE 3: FRIDAY GATEKEEPER AUDIT & QUEUE LOCK (14:00–16:00 JST)                                    │
│   • Run mandatory 5-Point Binary Gatekeeper Review on 100% of scheduled drafts.                      │
│   • Validate live endpoint URLs, test GA4 UTM parameters, verify Minpaku/license tags.              │
│   • Lock automated scheduling queue in Buffer, Meta Business Suite, and Substack.                    │
│                                      ▼                                                               │
│   PHASE 4: WEEKEND DISTRIBUTION & FIRST-HOUR ENGAGEMENT (Sat–Sun)                                    │
│   • Execute multi-timezone apex distribution (Window C: 21:00–23:30 JST US Morning Apex).             │
│   • Monitor first-hour replies, quote-tweets, and direct inquiries.                                  │
│   • Cross-post key releases to Discord #ecosystem-updates and Telegram community desk.               │
│                                      ▼                                                               │
│   PHASE 5: MONDAY MEASUREMENT, SYNTHESIS & RETROSPECTIVE (08:30–09:00 JST)                           │
│   • Pull 24-hour and 7-day conversion telemetry (Hard Outcomes vs Vanity Metrics).                   │

│                                                                                                      │
```
